# Historical Results

Every quantitative file in this directory predates the corrected MNIST label
mapping. The old code subtracted one from raw labels, incorrectly changing the
semantic identities of digits 1 through 9 and mapping raw 10 to 9.

These text files and plots are retained as historical coursework artifacts only.
They are stale and must not be reported as results from the current implementation.
New runs write to `part2/outputs/`.
